# Emmanuel Akinbo — Portfolio

![Social preview](public/emmanuel-akinbo-og-v2.jpg)

Personal portfolio for **Emmanuel Akinbo**, a Senior Frontend Engineer building fast, accessible, and scalable web products with React, Next.js, and TypeScript.

**Live site:** [emmanuelakinbo.vercel.app](https://emmanuelakinbo.vercel.app)

## Highlights

- Responsive layouts designed for mobile, tablet, and desktop screens.
- Light and dark themes that respect the visitor's system preference.
- Smooth page transitions and a mode-aware loading experience.
- Selected work and earlier-project case studies.
- Resume, services, and accessible contact flow with spam protection.
- Search-ready metadata: canonical URLs, sitemap, robots rules, JSON-LD, and social-sharing cards.
- Automated GitHub Actions checks for linting, type safety, and production builds.

## Built with

- [Next.js](https://nextjs.org/) 16

## Run locally

### Prerequisites

- Node.js 22 or later
- npm

### Installation

```bash
git clone https://github.com/akinbo-emmanuel/my-portfolio.git
cd my-portfolio
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available commands

```bash
npm run dev       # Start the development server
npm run lint      # Run ESLint
npx tsc --noEmit  # Check TypeScript types
npm run build     # Create a production build
npm start         # Run the production build locally
```

## Contact form

The contact form submits through [Web3Forms](https://web3forms.com/). Its submission access key is intentionally public because it identifies the form endpoint rather than granting account access. A honeypot field helps filter automated spam submissions.

## SEO and sharing

The site includes:

- `robots.txt` and `sitemap.xml` generated by Next.js.
- Canonical URLs and page-specific metadata.
- Person JSON-LD structured data.
- Open Graph and Twitter cards with a 1200 × 630 social preview image.

## Deployment

The portfolio deploys on [Vercel](https://vercel.com/). Every push to `master` runs GitHub Actions checks for linting, type-checking, and a production build.
